## Mengapa JavaScript?

JavaScript adalah bahasa pemrograman yang berjalan di browser dan juga di server (Node.js). Pada panduan ini, kita akan melihat fitur modern yang sering digunakan.

## Fitur ES6+ yang Sering Dipakai

- Arrow functions
- let / const
- Template literals
- Modules (import / export)

## Contoh Async/Await

```js
async function fetchData(url) {
  const res = await fetch(url);
  return await res.json();
}
```
